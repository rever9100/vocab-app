# 错词抄写本 · 背单词 PWA

一个可以离线使用、可安装到桌面/手机的背单词小应用。核心特色是**答错的词会自动安排抄写巩固**，配合艾宾浩斯记忆曲线安排复习。

在线地址：https://rever9100.github.io/vocab-app/

## 功能

**内置两本词书**
- 四级词汇（4441 词，每个词都带例句和中文翻译）
- 六级词汇（2083 词）

打开就能在"词书"页选择、切换，每本词书的学习进度各自独立保存，互不影响。

**自己导入词书**
在"导入"页粘贴或上传自己的词表（考研、雅思、专四专八等），会存进一本叫"我的词库"的自建词书。支持的格式（每行一个词）：
- `单词,释义,例句`（例句可省略）
- `单词[Tab]释义`
- `单词 - 释义`

**两种测试模式**（可在设置里勾选）
- 英译中：看英文，回想中文释义
- 中译英：看中文，拼写出英文单词
- 两种模式都有"不知道"按钮，不会的词直接跳过，算作答错

**艾宾浩斯复习曲线**
每个词按 1 → 2 → 4 → 7 → 15 → 30 天的间隔安排复习：
- 答对：前进到下一个更长的间隔
- 答错：打回第一天，重新开始
- 走完整个间隔表就标记为"已掌握"

每天优先复习到期的旧词，再补充新词。每日新词数量可在设置里调整（默认 30）。

**错词抄写**
一个词累计答错达到设定的次数，就会触发抄写巩固。抄写方式有三种（在设置里选）：
- 打字抄写：在格子里把单词打对 3 遍才算完成
- 手写抄写：在纸上抄，抄完一遍点一下按钮确认
- 不抄写：答错就跳过，不罚抄

**其它**
- 错词本：单独查看、巩固当前词书里错过的词
- 连续打卡天数统计
- 数据保存在本地浏览器，离线可用；换设备/清缓存不会同步

## 隐私

所有学习数据都存在你自己浏览器的本地存储里，不上传任何服务器。分享给别人时，每个人的进度各自独立、互不可见。

## 技术说明

纯静态网页（HTML + CSS + 原生 JavaScript），无后端、无框架依赖。通过 Service Worker 实现离线缓存，通过 manifest 支持"添加到主屏幕"安装为 PWA。词书数据内置在 wordbooks-data.js 里。

文件构成：
```
index.html           主程序（界面 + 全部逻辑）
wordbooks-data.js     内置词书数据
manifest.json         PWA 安装配置
service-worker.js     离线缓存
icon-192.png / icon-512.png   应用图标
```
